## 两类文档的分工

- **01-信息图形数据逻辑**：沉淀五类信息图形的概念与方法，按 A—E 五个维度分析：A 基本数据逻辑；B 统计图形与计算方式；C 视觉编码；D 数据/信息架构；E 视觉叙事架构。此目录不保存案例图片，通过 Markdown 相对链接关联案例报告。
- **02-信息图形类型案例**：保存案例图片、来源资料、逐例分析报告和分类说明。分类说明根据实际案例逐步总结，不把未经案例验证的推断写成定论。

## 案例维护流程

1. 收到案例图及必要背景后，先建立原始案例记录。
2. 为每个案例撰写独立分析报告，区分图中可观察事实、数据推断和待确认信息。
3. 将报告链接加入对应分类目录及相关数据逻辑文档。
4. 随案例积累，更新分类说明中的共性原则、方法、适用条件与边界。
5. 若新案例与旧结论冲突，保留差异并注明适用条件，不强行统一。
