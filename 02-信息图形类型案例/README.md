# 02 信息图形类型案例

本目录用于保存用户提供的案例图、案例原始资料及逐例分析报告。案例说明文档应由实际案例证据归纳，不以通用定义替代案例分析。

## 分类目录
- [混合型信息图形（Mixed Charts）](./01-混合型信息图形（Mixed%20Charts）/README.md)
- [文字型/列表型信息图形（Informational / List Infographics）](./02-文字型-列表型信息图形/README.md)
- [时间轴型信息图形（Timeline Infographics）](./03-时间轴型信息图形/README.md)

## 案例录入与更新规则
1. 保留用户提供的原始案例图，不擅自改变案例内容。
2. 每个案例建立独立分析报告，记录来源、图形结构、数据逻辑、统计方法、视觉编码、信息架构和视觉叙事。
3. 分类说明文档只归纳该类多个案例反复出现且有证据支持的原则、方法和边界。
4. 新案例与既有结论不一致时，记录差异、适用条件和待验证问题，不强行归并。
5. 案例图片保存在本目录对应分类下；“01-信息图形数据逻辑”中的定义文档只通过相对链接引用案例报告，不复制图片。
